# metuxa wordmark

The README uses the project mascot unchanged from `data/branding/metuxa-tux.png` on the left, with the lowercase wordmark on the right. The two SVGs provide readable text on light and dark GitHub themes.

The SVG text matches the GTK header in `client/gtk/main_window.cpp`: 24 px, font weight 800, letter spacing −1 px, enlarged uniformly by four. Noto Sans is the first font, followed by Cantarell and system sans-serif fallbacks. Rendering can vary with installed fonts.

The screenshot in `docs/assets/control-panel.png` is an unchanged copy of the stopped-state isolated GTK UI test. It contains no pairing details, network addresses or captured desktop content.
